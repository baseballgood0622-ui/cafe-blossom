# Cafe Blossom（カフェ ブロッサム）公式ホームページ

来月、地元商店街にオープンする架空の個人経営カフェ **「Cafe Blossom（カフェ ブロッサム）」** の1ページ完結型公式ホームページ制作課題です。

> ※本サイトに掲載している店舗名・住所・最寄り駅・メニュー価格等はすべて課題制作のための**架空の設定**であり、実在の店舗・団体とは関係ありません。

---

## 1. コンセプト・デザイン方針

- **テーマ**：「ちょっと寄り道、していきませんか？ ― 好きなことを、好きなだけ。」
- **ターゲット**：カフェ巡りが好きな女性、友人とのお出かけを楽しむ人、ひとりでゆっくり過ごしたい人
- **配色**：ウォームクリーム（`#FDFBF7`）・ソフトピンクベージュ（`#F5E9E6`）・ピュアホワイト（`#FFFFFF`）をベースに、文字色には目に優しいエスプレッソブラウン（`#3D2E2A`）を採用
- **フォント**：丸みのある親しみやすさと上品さを兼ね備えた `Zen Maru Gothic` と `Quicksand` / `Cormorant Garamond`（Google Fonts）を使用
- **レスポンシブ対応**：パソコン・タブレット・スマートフォンのすべての画面幅に対応

---

## 2. ページ構成（収録セクション）

1. **ヘッダー（Header）**：店名テキストロゴ（後からロゴ画像 `<img>` へ差し替え可能な設計）、ページ内ナビゲーション（`Concept` / `Menu` / `Shop Info`）、スマホ用ドロワーメニュー
2. **メインビジュアル（Hero）**：カフェ店内写真をフルスクリーン背景に敷いた1行キャッチコピー＆サブタイトル
3. **コンセプト紹介（Concept）**：導入リード文と、写真・文章の配置に変化をつけた2つのこだわり紹介
4. **おすすめメニュー（Menu）**：写真を主役にした4品のメニューカード（自家製いちごタルト／ふんわりカフェラテ／季節のフルーツパンケーキ／本日の焼き菓子プレート）
5. **店舗情報（Shop Info）**：店名・架空住所・営業時間（10:00〜18:00）・定休日（毎週水曜日）・電話番号（準備中表記＋後から発信リンク追加可能）
6. **アクセス（Access）**：Googleマップ埋め込み用エリア（現在は仮プレースホルダー表示・後から `<iframe>` に差し替え可能）および最寄り駅・道順案内
7. **おたより・お問い合わせ（Contact）**：ご用件・メッセージ内容を先、お名前・メールアドレスを後に配置した安心設計のサンプルフォーム
8. **フッター（Footer）**：店名、Instagramリンク枠（仮リンク `#` 設定・後から実URLへ変更可能）、ページ内リンク、コピーライト
